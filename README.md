
# 資產管理系統

公司內部使用的線上資產管理系統。</br>
純前端網頁（HTML + CSS + JavaScript），資料庫使用 Firebase Firestore，支援多人同時共用同一份資料，並有共用密碼登入保護。

一、功能特色</br>
1.資產管理</br>
(1)資產清單：勾選、查看／修改、資產編號（系統自動產生）、名稱、分類、保管人、所屬專案、地點、狀態，支援搜尋、篩選、分頁（可調整每頁筆數）</br>
(2)資產內頁：基本資訊、規格資訊、採購資訊（含財產價值）、歸屬資訊（公司／部門／專案／保管人／地點）、條碼列印</br>
(3)列印資產編號：勾選後可批次列印 Code128 條碼標籤</br>
(4)CSV 匯出／匯入：匯入前可下載範本，欄位標示必填，匯入時會逐列檢查資料是否正確，有問題會列出是第幾列、哪個欄位有誤</br>
(5)資產移轉紀錄：不可修改、不可刪除的稽核紀錄。手動新增，或是在資產內頁修改歸屬資訊（公司／部門／專案／保管人／地點）任一項並儲存時，系統會自動補一筆</br>
2.系統管理</br>
(1)組織架構（公司／部門）</br>
(2)人員管理（含公司／部門連動選單、CSV 匯入）</br>
(3)專案管理</br>
(4)地點管理</br>
(5)資產分類管理（階層瀏覽，先看大分類，點進去才看子分類）</br>
3.其他</br>
(1)登入保護：共用密碼登入，未登入無法讀取資料庫</br>
(2)多人即時共用：任何人打開網址，看到、編輯的都是同一份資料</br>
(3)自動儲存：新增／修改／刪除都會自動存檔，不用手動按儲存整批資料
